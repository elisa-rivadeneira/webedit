Quiero construir una pequeña herramienta web para empresarios y pequeños negocios que necesitan tener una página web sencilla, profesional y muy fácil de actualizar.

IMPORTANTE:
La imagen proporcionada junto con este prompt es la REFERENCIA VISUAL PRINCIPAL del proyecto.

Debes utilizar:

IMAGEN + ESTE PROMPT

como una única especificación.

No quiero que diseñes una página diferente a la mostrada en la referencia. La imagen representa la intención visual que debe tener el producto.

El objetivo no es crear un sistema complejo ni un sitio web institucional grande.

El objetivo es crear una página comercial sencilla que un empresario pueda mantener fácilmente, principalmente cambiando su información básica y sus imágenes promocionales.

==================================================
1. OBJETIVO DEL PRODUCTO
==================================================

Construir una página web pública para un pequeño negocio.

Puede utilizarse, por ejemplo, para:

- restaurantes;
- tiendas;
- pequeños comercios;
- emprendimientos;
- servicios profesionales;
- otros negocios que necesiten una presencia web sencilla.

La página debe funcionar como un escaparate digital.

El empresario no debe necesitar conocimientos técnicos para actualizarla.

Debe existir una sección /admin desde la cual pueda modificar el contenido principal del sitio.

La prioridad es:

SIMPLE → CLARO → PROFESIONAL → FÁCIL DE ACTUALIZAR

==================================================
2. PÁGINA PÚBLICA
==================================================

La página pública debe seguir visualmente la composición mostrada en la imagen de referencia.

Debe contener las siguientes áreas:

1. Cabecera
2. Sección principal / presentación
3. Sección de promociones
4. Redes sociales
5. Pie de página

No agregar otras secciones que no hayan sido solicitadas.

--------------------------------------------------
2.1 CABECERA
--------------------------------------------------

En la parte superior debe aparecer:

- logo del negocio;
- nombre o identidad visual del negocio;
- navegación sencilla.

La cabecera debe transmitir una sensación profesional y limpia.

La navegación debe ser sencilla y no debe sobrecargar la página.

--------------------------------------------------
2.2 SECCIÓN PRINCIPAL
--------------------------------------------------

Debe existir una sección principal visualmente atractiva.

Debe contener:

- título principal;
- texto descriptivo;
- imagen principal de ambiente/producto;
- composición visual similar a la referencia.

El título y el texto deben poder modificarse desde /admin.

La imagen principal también debe poder reemplazarse desde /admin.

El diseño debe mantener una jerarquía visual clara:

primero el mensaje principal,
después la descripción,
y luego el contenido promocional.

--------------------------------------------------
2.3 PROMOCIONES
--------------------------------------------------

Debe existir una sección claramente identificada como promociones.

La referencia muestra dos promociones.

Cada promoción se representa mediante una imagen completa.

MUY IMPORTANTE:

La promoción ya viene diseñada como una imagen.

El sistema NO debe intentar construir el flyer.

La imagen puede contener:

- texto;
- precio;
- producto;
- descuento;
- fechas;
- elementos gráficos;
- cualquier otra información de la promoción.

Por lo tanto, la página simplemente debe mostrar la imagen promocional.

No colocar textos adicionales encima o debajo de la imagen que dupliquen la información del flyer.

No crear botones "Ver más".

No crear una página individual para cada promoción.

No crear una descripción separada para cada promoción.

No agregar precios fuera de la imagen.

La imagen es la promoción completa.

--------------------------------------------------
2.4 INTERACCIÓN CON LAS PROMOCIONES
--------------------------------------------------

Cuando el visitante haga clic sobre una imagen promocional:

- la imagen debe abrirse ampliada;
- debe poder visualizarse con mayor detalle;
- no debe navegar a otra página;
- debe poder cerrarse y regresar a la página principal.

La experiencia debe ser sencilla y visual.

La imagen ampliada debe conservar la imagen original sin modificar su contenido.

--------------------------------------------------
2.5 REDES SOCIALES
--------------------------------------------------

Debajo de las promociones debe existir una sección sencilla con enlaces a las redes sociales del negocio.

La referencia visual muestra iconos para redes sociales.

Los enlaces deben poder configurarse desde /admin.

Como mínimo, permitir configurar los enlaces que formen parte del diseño aprobado.

No agregar redes sociales adicionales que no hayan sido solicitadas.

--------------------------------------------------
2.6 PIE DE PÁGINA
--------------------------------------------------

Debe existir un pie de página sencillo.

Debe mantener la estética visual general de la página.

Puede mostrar:

- logo;
- nombre del negocio;
- pequeño texto;
- información básica del sitio.

No convertir el pie de página en una sección compleja.

==================================================
3. PANEL /ADMIN
==================================================

Debe existir una sección de administración accesible mediante:

/admin

El objetivo del panel es que una persona sin conocimientos técnicos pueda actualizar el sitio.

Debe ser sencillo, claro y visual.

La referencia visual muestra el sitio público y el panel de administración.

El panel debe permitir editar solamente la información necesaria.

--------------------------------------------------
3.1 ACCESO
--------------------------------------------------

El usuario debe acceder al panel mediante usuario y contraseña.

Una vez autenticado, debe visualizar el panel de administración.

No crear diferentes niveles de usuarios ni permisos complejos.

--------------------------------------------------
3.2 ESTRUCTURA DEL PANEL
--------------------------------------------------

El panel debe presentar claramente las áreas editables.

Debe existir una navegación sencilla dentro del panel.

Debe existir un botón claramente visible:

"Guardar cambios"

Las modificaciones no deben aplicarse simplemente por cambiar un campo.

El usuario debe poder realizar sus modificaciones y después seleccionar "Guardar cambios".

--------------------------------------------------
3.3 LOGO
--------------------------------------------------

Debe existir una sección para cambiar el logo.

El administrador debe poder seleccionar/reemplazar la imagen del logo.

Debe existir una vista previa para que pueda comprobar qué imagen está utilizando.

--------------------------------------------------
3.4 INFORMACIÓN PRINCIPAL
--------------------------------------------------

Debe poder modificarse:

- título principal;
- texto descriptivo;
- imagen principal.

Los campos deben ser sencillos de editar.

No agregar campos adicionales que no formen parte del diseño aprobado.

--------------------------------------------------
3.5 PROMOCIÓN 1
--------------------------------------------------

Debe existir una sección claramente identificada como:

"Promoción 1"

El administrador debe poder:

- ver la imagen actual;
- reemplazarla por una nueva imagen.

La imagen subida representa la promoción completa.

No debe existir un editor complejo de promociones.

No deben existir campos separados para:

- precio;
- descuento;
- descripción;
- título de la promoción.

Toda esa información ya estará dentro de la imagen creada previamente por el empresario.

--------------------------------------------------
3.6 PROMOCIÓN 2
--------------------------------------------------

Debe existir una sección:

"Promoción 2"

Debe funcionar exactamente igual que Promoción 1.

El administrador debe poder reemplazar la imagen completa de la promoción.

--------------------------------------------------
3.7 REDES SOCIALES
--------------------------------------------------

Debe existir una sección para editar los enlaces de las redes sociales que aparecen en la página pública.

Cada red debe tener:

- nombre;
- icono;
- campo para introducir o modificar el enlace.

--------------------------------------------------
3.8 GUARDAR CAMBIOS
--------------------------------------------------

Debe existir un botón principal:

"Guardar cambios"

Al seleccionarlo:

1. deben validarse los datos necesarios;
2. deben guardarse los cambios;
3. debe mostrarse una confirmación clara al usuario;
4. cuando el usuario vuelva a la página pública, debe visualizar la información actualizada.

El comportamiento debe ser sencillo y comprensible.

==================================================
4. EXPERIENCIA DEL USUARIO
==================================================

La experiencia debe ser extremadamente sencilla.

Un empresario debe poder:

1. entrar a /admin;
2. iniciar sesión;
3. cambiar su información;
4. reemplazar sus promociones;
5. modificar sus enlaces;
6. guardar;
7. regresar a su página pública;
8. comprobar los cambios.

No debe necesitar conocimientos técnicos para realizar ninguna de estas acciones.

==================================================
5. DISEÑO VISUAL
==================================================

La imagen proporcionada es la referencia visual principal.

Respeta especialmente:

- distribución general;
- jerarquía visual;
- proporciones;
- espacios;
- tamaño relativo de los elementos;
- composición de la página;
- apariencia de las promociones;
- estructura del panel administrativo;
- estilo profesional y comercial;
- experiencia visual en móvil.

La página debe sentirse como un producto real y profesional, no como una plantilla genérica.

Debe existir una clara separación visual entre:

PÁGINA PÚBLICA

y

PANEL DE ADMINISTRACIÓN.

La página pública debe priorizar la presentación visual del negocio.

El panel debe priorizar la facilidad de edición.

==================================================
6. RESPONSIVE
==================================================

La página debe funcionar correctamente en:

- computadora;
- tablet;
- teléfono móvil.

La referencia visual también muestra una versión móvil.

En móvil:

- la navegación debe adaptarse correctamente;
- el contenido debe reorganizarse sin romper el diseño;
- las promociones deben seguir siendo fáciles de visualizar;
- las imágenes deben conservar sus proporciones;
- la interacción para ampliar una promoción debe funcionar correctamente.

No simplemente reducir toda la página.

Adaptar la composición manteniendo la intención visual de la referencia.

==================================================
7. LÍMITES DEL PROYECTO
==================================================

Esta primera versión debe mantenerse pequeña.

NO construir:

- tienda virtual;
- carrito de compras;
- sistema de pagos;
- catálogo complejo;
- páginas individuales para promociones;
- editor de flyers;
- editor de imágenes;
- sistema de publicaciones;
- blog;
- estadísticas;
- sistema de reservas;
- funcionalidades que no aparecen en la solución aprobada.

No agregar funciones solamente porque podrían ser útiles en el futuro.

Si una funcionalidad no está indicada en este prompt o claramente representada en la referencia visual, no debe agregarse a esta primera versión.

==================================================
8. CONTENIDO EDITABLE
==================================================

El administrador debe poder modificar únicamente:

- logo;
- nombre/identidad del negocio cuando corresponda al diseño;
- título principal;
- texto descriptivo;
- imagen principal;
- imagen de Promoción 1;
- imagen de Promoción 2;
- enlaces a redes sociales.

No crear campos adicionales innecesarios.

==================================================
9. REFERENCIA VISUAL
==================================================

La imagen proporcionada junto con este prompt debe considerarse la referencia visual principal.

No debes interpretar la imagen como una simple inspiración.

Debes utilizarla para reproducir la intención visual del producto.

La combinación:

IMAGEN + PROMPT

define el resultado esperado.

La imagen establece especialmente la distribución, jerarquía y apariencia general.

Este prompt establece el comportamiento, contenido editable y límites del producto.

No diseñes una solución diferente simplemente porque consideres que otra estructura podría ser mejor.

==================================================
10. CRITERIOS DE TERMINACIÓN
==================================================

La primera versión estará terminada cuando:

- exista la página pública;
- exista /admin;
- el administrador pueda iniciar sesión;
- pueda modificar el logo;
- pueda modificar el título y texto principal;
- pueda cambiar la imagen principal;
- pueda reemplazar las dos imágenes promocionales;
- pueda modificar los enlaces sociales;
- pueda guardar los cambios;
- los cambios aparezcan correctamente en la página pública;
- las promociones puedan abrirse ampliadas;
- la página funcione correctamente en computadora;
- la página funcione correctamente en móvil;
- el resultado visual respete la referencia proporcionada;
- no existan funcionalidades adicionales innecesarias.

IMPORTANTE:

Antes de considerar terminada la construcción, comprueba que el resultado visual y el comportamiento correspondan a la imagen de referencia y a todas las instrucciones anteriores.

No agregues complejidad que no haya sido solicitada.

La prioridad es construir una primera versión pequeña, funcional, clara y realmente utilizable.
